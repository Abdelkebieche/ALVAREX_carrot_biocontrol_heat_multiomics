# Annotation inputs

Some biological annotation resources are required but were not included in the supplied export:

- DH13M14 functional annotation table (`Daucus_carota_DH13M14.txt`);
- gene-ID map between project IDs and PlanT2T IDs;
- HSP candidate annotation table;
- KEGG-derived functional-family input folders.

Their expected paths are configured in `config/config.R`. See `docs/05_functional_dictionaries.md`.
