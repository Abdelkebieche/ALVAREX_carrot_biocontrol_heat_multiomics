# Metabolomics inputs

Expected local inputs:

- `lcms_features.csv`: processed Compound Discoverer feature table;
- `metadata.csv`: sample metadata with `Sample`, `Genotype`, `Temperature`, `Treatment`, and `Sampling_time`.

The manuscript reports 17,846 retained UHPLC-HRMS features across 120 samples. Raw vendor files and private Compound Discoverer projects are not included.
