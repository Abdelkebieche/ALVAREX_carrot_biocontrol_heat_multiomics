# Metadata

`rnaseq_metadata.csv` contains the supplied RNA-seq experimental metadata for PRESTO and ROBILA. It covers D0/P1, D2/P2 and D4/P3 and includes block/replicate information.

The **six-genotype disease experiment** is broader than the omics datasets. Transcriptomic and metabolomic analyses in the manuscript were restricted to PRESTO and ROBILA; the phenotype experiment included DEEP, NANT, NEVA, OXHELLA, PRESTO and ROBILA.
